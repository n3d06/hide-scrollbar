1. Overview & Core Purpose

ScrollHide is an ultra-lightweight browser extension designed to eliminate ugly, intrusive scrollbars across websites, giving you a clean, distraction-free browsing experience.

  • Non-destructive Scrolling: Scrolling continues to work seamlessly via mouse wheel, trackpad gestures, keyboard arrow keys, Space, Page Up / Page Down, and touch inputs.
  • Zero Resource Overhead: Uses pure CSS rules and reactive event hooks instead of CPU-heavy JavaScript scroll listeners.
  • Privacy First: Operates entirely offline on your device with no data telemetry or tracking.

2. Extension Popup Controls

  • Main Power Toggle (⏻): Click the large center button to turn scrollbar hiding ON or OFF globally across all tabs.
  • Active Domain Indicator: Displays the hostname of the current web page.
  • Quick Whitelist (+ / −): Click to add or remove the current website to/from your exceptions list with a single click.
  • Statistics Panel:
    • Status: Shows whether scrollbars are currently Active (hidden), Disabled, Whitelisted, or Restricted on this page.
    • Exceptions: Total number of custom whitelisted domains.
    • Cleaned: Counter tracking total scrollbars hidden during your browsing sessions.
  • Toolbar Buttons: Fast access to Export, Import, and the Dashboard / Settings page.

3. Whitelist & Exceptions Management

The Whitelist tab provides a full-featured code editor to manage websites where original scrollbars should be preserved:

  • Format: Enter one domain per line (e.g. youtube.com or docs.google.com). Protocols like https:// or trailing slashes are automatically sanitized.
  • Comments Support: Organize your list with comments by starting lines with ! or # (e.g. ! Work Applications). Comments are ignored when saving.
  • Apply & Revert: The Apply changes button activates whenever changes are made. Use Revert to discard unsaved edits.
  • Keyboard Shortcut: Press Ctrl + S (or Cmd + S on macOS) inside the editor to quickly save your changes.
  • Import & Export: Easily export your whitelist as plain text .txt or import lists to append new domains.

4. Toolbar Status Icons

Pin the extension icon to your browser toolbar to monitor status in real-time:

  • Active (Normal Icon): Scrollbar hiding is currently active on the tab you are viewing.
  • Inactive (Grayscale Icon): Extension is globally disabled, page is in your Whitelist, or internal browser page.

5. Frequently Asked Questions & Troubleshooting

  • Q: Can I still scroll when scrollbars are hidden?
    A: Yes, 100%! All scrolling methods (mouse wheel, touchpad gestures, arrow keys, touchscreens) continue to function exactly as normal.
  • Q: What should I do if scrollbars do not hide immediately on a tab?
    A: Simply reload the tab (F5 or Ctrl + R) so the latest styling takes effect immediately.
  • Q: Why does the popup say "Restricted page" on some URLs?
    A: Modern browsers strictly prohibit extensions from injecting scripts into internal system pages (like chrome://settings or about:blank) for security.
  • Q: What if a web app has custom canvas scrollbars?
    A: Websites rendering custom canvas-based scrollbars (like certain PDF viewer engines) cannot be altered via standard CSS rules.

Privacy Policy

ScrollHide does not collect, store, or transmit any browsing data. Everything is 100% offline.
  • Zero Data Collection: No analytics, no tracking, and zero telemetry.
  • Local Storage Only: Whitelist entries and preferences stay strictly on your local browser profile.
  • No External Requests: The extension operates without connecting to any external servers.

Permissions Explanation

  • storage: Used solely to save your on/off preference and website whitelist.
  • tabs / scripting: Used to inject the minimal stylesheet that hides scrollbars on web pages.
  • <all_urls>: Necessary to apply the cleaner scrollbar view across any web page you browse.
